## 소개

길 건너편 보행 신호등을 카메라로 자동 감지하고 전체화면으로 확대하여,
저시력자가 신호 색상을 쉽고 빠르게 확인할 수 있도록 돕는 웹 앱입니다.

별도 설치 없이 브라우저에서 바로 사용할 수 있습니다.

**[지금 사용해보기 →](https://mirnet96.github.io/traffic-light)**

## 주요 기능

- **실시간 감지** — 서버 YOLOv11s 추론으로 2~10차선 건너편 신호등 자동 탐지
- **원거리 감지** — 박스 높이 2% 이상 신호등까지 감지 (원거리 모드)
- **전체화면 자동 확대** — 감지 즉시 전체화면으로 확대, 정지·보행 상태 크게 표시
- **TTS 음성 안내** — 카메라 시작부터 신호 감지까지 전 과정 한국어 음성 안내
- **야간 모드** — 주변 밝기 자동 측정 후 필터 적용, 수동 전환도 지원
- **진동 피드백** — 신호 감지 시 햅틱 진동 (보행: 200ms / 정지: 100-50-100ms)
- **카메라 전환** — 전·후면 카메라 전환 지원
- **디버그 녹화** — 설정에서 활성화 시 카메라 영상을 .webm 파일로 저장

## 사용 방법

1. 브라우저에서 [https://mirnet96.github.io/traffic-light](https://mirnet96.github.io/traffic-light) 접속
2. 시작 전 설정 화면에서 원하는 옵션 선택
   - 음성 알림 On/Off
   - 디버그 로그 On/Off
   - 디버그 녹화 On/Off
3. **카메라 시작** 버튼 탭 → 카메라 권한 허용
4. 건너편 신호등에 카메라를 향하기
5. 신호등 감지 시 전체화면으로 자동 확대
6. 화면 아무 곳이나 탭하면 카메라 뷰로 복귀

> HTTPS 환경에서만 카메라 API가 동작합니다. GitHub Pages는 기본 HTTPS 지원.

## 신호등 색상 판별 (v0.4 — 구조 인식 기반)

v0.4 에서 색상 추정 로직을 전면 개선했습니다.

### 신호등 구조 자동 판별

감지된 박스의 세로/가로 비율(H/W)로 신호등 유형을 자동 분류합니다.

| H/W 비율 | 구조 | 설명 |
|---|---|---|
| 1.8 이상 | 3구 세로형 | 상단=정지(적), 중단=보행(녹), 하단=잔여시간(녹) |
| 0.65~1.8 | 2구 세로형 | 상단=정지(서있는사람·적색), 하단=보행(걷는사람·녹색) |

### 판정 원리

단순히 박스 전체의 평균 색상을 보던 방식에서 벗어나, **어느 구간에 빛이 집중되는지**를 먼저 파악한 뒤 그 구간의 색상으로 판정합니다.

- 구간별 평균 밝기를 비교해 점등된 등의 위치(상단/하단)를 특정
- 점등 구간의 HSV 색상 + 발광 픽셀 밀도로 신뢰도 검증
- 단색 구조물(방음벽·간판) 오판 방지: 밝기 분산 필터 적용
- 상단에만 초록이 감지되는 경우 배경 간판으로 판단하여 unknown 처리

## 로컬 실행

카메라 API는 HTTPS 또는 `localhost`에서만 동작합니다.

```bash
git clone https://github.com/mirnet96/traffic-light
cd traffic-light

# Node.js
npx serve .

# Python
python -m http.server 8080
```

브라우저에서 `http://localhost:8080` 접속.
