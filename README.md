# [BETA] 신호등 알리미 Pro (Traffic Light Pro)

> **주의: 본 서비스는 현재 v0.5 테스트 및 개발 단계에 있습니다.**
> 8~10차선 대형 교차로 인식을 위한 멀티 스케일 줌 스캔 기능이 추가되었습니다.

---

## 1. 멀티 스케일 줌 스캔 (Multi-scale Zoom Scanning) 절차
본 시스템은 원거리 신호등의 가독성을 높이기 위해 매 프레임마다 세 가지 줌 레벨을 순환하며 스캔합니다.

### [단계별 스캔 프로세스]
1. **WIDE 스캔 (1x):** 화면 상단 전체 영역을 탐지하여 근거리 및 중거리 신호등을 포착합니다.
2. **MID 스캔 (2x):** 화면 중앙부를 2배 확대하여 4~6차선 거리의 신호등 형태를 정밀하게 분석합니다.
3. **TELE 스캔 (4x):** 소실점(도로 끝) 부근을 4배 확대하여 10차선 이상의 초원거리 신호등 후보지를 탐색합니다.

### [좌표 역매핑 (Coordinate Mapping)]
- 각 줌 레벨에서 탐지된 객체는 `vision-worker.js`에서 원본 이미지 좌표계로 즉시 역산됩니다.
- 줌 영역에서 계산된 `(Local X, Y)`를 `(Global X, Y)`로 변환하여 화면 렌더링 및 색상 분석 엔진에 전달합니다.

---

## 2. 핵심 알고리즘 및 기술 스택
- **AI 엔진:** Google MediaPipe (후보지 탐색) & YOLOv8n (정밀 검증)
- **전처리:** Laplacian Sharpening 필터를 통한 원거리 객체 경계선 강화.
- **분석:** HSV(Hue, Saturation, Value) 색 공간 분석을 통한 신호 상태(RED/GREEN) 판별.
- **최적화:** Web Worker 기반 비동기 처리로 UI 메인 스레드 점유 최소화 (60fps 목표).

---

## 3. 사용 가이드
1. **카메라 각도:** 스마트폰을 지면과 수평이 되도록 들고 정면을 향하게 하십시오.
2. **인식 범위:** 줌 스캔 기능을 통해 최대 50m 이상의 신호등까지 탐지가 가능합니다.
3. **피드백:** 신호가 감지되면 화면 확대와 함께 TTS 음성 안내 및 진동 알림이 제공됩니다.
